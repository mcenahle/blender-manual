**********************
Selecting in Draw Mode
**********************

Draw Mode selects complete Grease Pencil strokes. To select individual points
or work with point and segment selections, switch to
:doc:`Edit Mode </grease_pencil/modes/edit/introduction>`.


Selection Tools
===============

The selection tools are documented in the
:doc:`Grease Pencil selection </grease_pencil/modes/selection>` section. In
Draw Mode, the Tweak, Box, Circle, and Lasso tools select complete strokes.
