Stroke Menu
***********

The *Stroke* menu contains operations for editing selected strokes. Most of
these operators are shared with Edit Mode and are documented on the
:doc:`Grease Pencil Editing </grease_pencil/modes/stroke_editing>` page.

Paste Active
============

.. reference::

   :Mode:      Draw Mode
   :Menu:      :menuselection:`Stroke --> Paste Active`

Pastes copied strokes to the active layer.


Paste by Layer
==============

.. reference::

   :Mode:      Draw Mode
   :Menu:      :menuselection:`Stroke --> Paste by Layer`

Pastes copied strokes to their corresponding layers.
