Selection Tools
===============

:ref:`Tweak <tool-select-tweak>`
   Select or move strips.
:ref:`Select Box <tool-select-box>`
   Select strips by dragging a box. All strips that intersect the box are selected.
:ref:`Select Circle <tool-select-circle>`
   Select strips by dragging a circle. All strips that intersect the path of the circle are selected.
:ref:`Select Lasso <tool-select-lasso>`
   Select strips by drawing a lasso.


Editing Tools
=============

:doc:`Blade <blade>`
   Cut strips with a point or box gesture.
:doc:`Slip <slip>`
   Move strip content without changing the strip's position or duration.
